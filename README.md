# 💰 Meu Controle Financeiro

## 📌 Sobre o projeto

Projeto desenvolvido em Python para calcular despesas mensais e o saldo restante do usuário.

O programa permite informar o salário e os gastos com alimentação, transporte e aluguel. Após receber os valores, calcula o total das despesas e o saldo disponível.

Também apresenta um aviso quando as despesas ultrapassam a renda mensal.

## 🐍 Tecnologias e conhecimentos utilizados

- Python
- `print()` e `input()`
- Variáveis
- Conversão de valores com `float()`
- Operações matemáticas
- F-strings e formatação de valores
- Estruturas condicionais `if` e `else`

## 📚 O que aprendi

Este é um dos meus primeiros projetos desenvolvidos durante meus estudos de Python.

Com ele, pratiquei a entrada de dados, o uso de variáveis, cálculos matemáticos e estruturas condicionais.

Também aprendi a importância da indentação para organizar os blocos de código e controlar a execução das instruções.

## ▶️ Como executar

1. Tenha o Python instalado no computador.
2. Baixe os arquivos do projeto.
3. Abra a pasta no terminal.
4. Execute o comando:

```python
python main.py
```
